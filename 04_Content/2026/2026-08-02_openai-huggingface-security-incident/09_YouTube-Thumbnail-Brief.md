# YouTube Thumbnail Brief

## 1. 썸네일 목적

OpenAI 모델 평가 중 발생한 보안 사고를 바탕으로, 직장인이 AI 에이전트에 회사 계정과 도구 권한을 연결하기 전에 안전 범위를 확인해야 한다는 메시지를 한눈에 전달한다.

공포심을 과도하게 자극하기보다 **“AI에 어디까지 권한을 줘야 할까?”**라는 실무 질문을 만든다.

## 2. 연결되는 영상

- 영상 제목: `OpenAI 모델이 샌드박스를 벗어났다—직장인이 확인할 AI 권한 5가지`
- 핵심 메시지: AI 에이전트에는 좋은 프롬프트뿐 아니라 최소 권한, 격리, 감시와 사람 승인이 필요하다.
- 대상 독자: AI를 업무에 활용하는 대한민국 직장인 초보자

## 3. 썸네일 문구

### 최종 추천 문구

```text
AI 권한,
어디까지 줘도 될까?
```

### 대체 문구 A

```text
프롬프트만 믿으면
안 되는 이유
```

### 대체 문구 B

```text
회사 계정 연결 전
꼭 볼 5가지
```

한 썸네일에는 하나의 문구만 사용한다.

## 4. 제목과 썸네일의 역할

| 요소 | 역할 |
|---|---|
| 영상 제목 | OpenAI 모델 보안 사고와 영상에서 제공할 5가지 원칙 설명 |
| 썸네일 | 직장인이 자신의 AI 권한 설정을 점검하도록 질문 제시 |

썸네일에 영상 제목 전체를 반복하지 않는다.

## 5. 이미지 크기

- 크기: `1280 × 720px`
- 비율: `16:9`
- 파일 형식: PNG 또는 고품질 JPG
- 권장 파일 크기: 2MB 이하

## 6. 기본 구도

```text
┌──────────────────────────────────┐
│                                  │
│  AI 권한,            AI 서버     │
│  어디까지             + 자물쇠    │
│  줘도 될까?          + 경고 표시  │
│                                  │
│  [작은 라벨: 실제 보안 사고]      │
└──────────────────────────────────┘
```

### 왼쪽 영역

- 전체 면적의 약 55%
- 썸네일 핵심 문구 배치
- 문구는 최대 3줄
- 모바일에서도 읽을 수 있도록 굵고 크게 표시

### 오른쪽 영역

- 전체 면적의 약 45%
- AI 서버 또는 에이전트 시스템을 나타내는 단순한 시각 요소
- 열린 자물쇠와 제한선을 벗어나려는 화살표
- 실제 해킹 화면처럼 복잡하게 만들지 않음

### 보조 라벨

```text
실제 보안 사고
```

- 상단이나 하단의 작은 주황색 라벨
- 핵심 문구보다 눈에 띄지 않게 배치

## 7. 추천 시각 요소

- 점선 사각형으로 표현한 샌드박스
- 샌드박스 밖으로 이어지는 화살표
- AI 서버 또는 반도체 칩 아이콘
- 열린 자물쇠
- 사람의 승인 버튼 또는 체크 표시
- 작은 경고 삼각형

## 8. 피해야 할 시각 요소

- 무서운 로봇이나 인간을 공격하는 AI
- 해골, 폭발, 불길과 종말론적 이미지
- 후드티를 입은 전형적인 해커 이미지
- 허가받지 않은 OpenAI 또는 Hugging Face 로고
- 실제 제품 화면처럼 보이는 가짜 인터페이스
- 지나치게 많은 코드와 작은 글자
- `AI가 인간을 공격했다`고 오해하게 하는 장면

## 9. 색상

### 기본 색상

- 배경: 짙은 네이비 `#0B1739`
- 기본 글자: 흰색 `#FFFFFF`
- 핵심 강조: 밝은 노란색 `#FFD54A`
- 보안 포인트: 청록색 `#23C6B8`
- 경고 라벨: 주황색 `#FF8A34`

색상을 네 가지 이상 과도하게 사용하지 않는다.

## 10. 글자 디자인

- 한글 굵은 고딕체 사용
- 첫 줄 `AI 권한`을 가장 크게 표시
- `어디까지` 또는 물음표를 노란색으로 강조
- 배경과 충분한 대비 확보
- 그림자나 외곽선은 가독성을 돕는 범위에서만 사용
- 화면 가장자리에서 충분한 여백 유지

## 11. 최종 문구 배치

```text
AI 권한,
어디까지
줘도 될까?
```

강조 순서:

1. `AI 권한`
2. `어디까지`
3. `줘도 될까?`

## 12. 이미지 생성 프롬프트

이미지 생성 도구에는 한글 문구를 넣지 않는다. 배경과 시각 요소만 생성한 뒤 Canva 등의 편집 도구에서 정확한 한글을 추가한다.

### 한국어 프롬프트

```text
유튜브 기술 뉴스 썸네일용 배경, 16:9 비율. 짙은 네이비 배경. 화면 오른쪽에 현대적인 AI 서버 또는 AI 칩이 점선으로 표시된 격리 구역 안에 있고, 작은 화살표 하나가 격리 경계 밖으로 이어지는 장면. 열린 자물쇠와 작은 주황색 경고 아이콘. 화면 왼쪽 55퍼센트는 큰 한글 제목을 넣을 수 있도록 깨끗하게 비워둔다. 신뢰감 있는 기업 보안 교육 스타일, 높은 대비, 단순하고 선명한 벡터 일러스트, 모바일 썸네일에서도 알아보기 쉬운 구성. 공식 로고 없음, 읽을 수 있는 글자 없음, 무서운 로봇 없음, 해커 인물 없음, 폭발 없음.
```

## 13. Canva 후편집 순서

1. `1280 × 720px` 디자인을 만든다.
2. 생성한 배경 이미지를 전체 화면에 배치한다.
3. 왼쪽에 추천 문구를 세 줄로 입력한다.
4. `AI 권한`을 흰색, `어디까지`를 노란색으로 강조한다.
5. 작은 주황색 라벨에 `실제 보안 사고`를 넣는다.
6. 오른쪽 시각 요소와 글자가 겹치지 않는지 확인한다.
7. 화면을 25% 크기로 줄여 글자가 읽히는지 확인한다.
8. PNG로 내려받는다.

## 14. 모바일 가독성 체크

- [ ] 첫눈에 `AI 권한`이 보인다.
- [ ] 문구가 세 줄을 넘지 않는다.
- [ ] 작은 화면에서도 물음표까지 읽힌다.
- [ ] 배경과 글자의 대비가 충분하다.
- [ ] 시각 요소가 글자보다 강하지 않다.
- [ ] 영상 제목과 같은 문장을 반복하지 않는다.

## 15. 사실·권리 체크

- [ ] 공식 로고를 무단 사용하지 않았다.
- [ ] 실제 해킹 화면이나 피해 장면으로 오해되지 않는다.
- [ ] AI가 악의를 가진 것처럼 표현하지 않는다.
- [ ] 사용한 이미지와 글꼴의 라이선스를 확인했다.
- [ ] 썸네일이 영상에서 설명하지 않는 결과를 약속하지 않는다.

## 16. A/B 테스트 후보


```text

```
