# Content Production SOP

> Sunny AI 콘텐츠 회사의 표준 콘텐츠 제작 절차

## 1. Purpose

이 문서는 AI 뉴스나 실무 주제를 신뢰할 수 있는 고품질 콘텐츠로 제작하기 위한 표준 작업 절차를 정의한다.

모든 에이전트는 `00_Company/Sunny.md`의 비전, 원칙, 말투, 품질 기준을 우선 적용한다.

## 2. Standard Workflow

```text
주제 요청
→ 자료 수집
→ 출처 검증
→ 주제 선정
→ 콘텐츠 기획
→ 원고 작성
→ 시각·영상 기획
→ 플랫폼별 재구성
→ 품질 검수
→ 사람의 최종 승인
→ 발행 및 성과 기록
```

## 3. Step 1 — 요청 정의

### 담당

Sunny CEO Agent

### 확인 항목

- 콘텐츠의 목적
- 핵심 독자
- 다룰 주제 또는 질문
- 필요한 결과물
- 사용할 플랫폼
- 마감일과 우선순위

### 필수 입력 양식

```text
목적:
대상 독자:
주제:
결과물:
플랫폼:
마감일:
특별 요청:
```

정보가 부족하면 임의로 확정하지 않고 `확인 필요`로 표시한다.

## 4. Step 2 — 자료 수집

### 담당

News Agent

### 작업

- 공식 발표와 원문을 우선 수집한다.
- 신뢰할 수 있는 보조 출처를 추가한다.
- 발표일과 실제 사건 발생일을 구분한다.
- 중복 기사와 단순 재인용 기사를 제거한다.
- 중요한 주장마다 근거 URL을 남긴다.

### 출처 우선순위

1. 기업·기관의 공식 발표 및 공식 문서
2. 연구 논문과 공공기관 자료
3. 신뢰할 수 있는 전문 매체
4. 기타 자료는 참고용으로만 사용

### 산출물

```text
제목:
원문 URL:
발표일:
핵심 사실:
직장인 관련성:
미확인 사항:
```

## 5. Step 3 — 출처 및 사실 검증

### 담당

News Agent, QA Agent

### 검증 기준

- 원문에 실제로 존재하는 내용인가?
- 숫자, 날짜, 제품명, 인물명이 정확한가?
- 사실과 전망 또는 의견이 구분되어 있는가?
- 최신 정보인지 확인했는가?
- 이미지와 인용문을 사용할 권리가 있는가?

검증할 수 없는 내용은 삭제하거나 `확인되지 않음`이라고 명시한다.

## 6. Step 4 — 주제 선정

### 담당

Editor Agent

### 평가 기준

각 항목을 1점부터 5점까지 평가한다.

| 기준 | 평가 질문 |
|---|---|
| 신뢰성 | 근거가 충분하고 검증 가능한가? |
| 시의성 | 지금 다룰 이유가 있는가? |
| 관련성 | 직장인과 기업 업무에 관련이 있는가? |
| 활용성 | 독자가 바로 적용할 수 있는가? |
| 이해도 | 초보자에게 쉽게 설명할 수 있는가? |
| 차별성 | Sunny만의 실무 해석을 더할 수 있는가? |
| 확장성 | 여러 콘텐츠 형식으로 발전시킬 수 있는가? |

### 선정 규칙

- 신뢰성 점수가 4점 미만이면 보류한다.
- 총점이 높은 주제를 우선 제작한다.
- 조회 가능성만으로 주제를 선정하지 않는다.
- 독자에게 줄 실질적 가치가 없으면 제작하지 않는다.

## 7. Step 5 — 콘텐츠 기획

### 담당

Planning Agent

### 기본 구조

1. 한 문장 핵심 메시지
2. 독자의 문제 또는 관심을 보여주는 도입
3. 무엇이 달라졌는지 설명
4. 왜 중요한지 설명
5. 직장인의 업무에 미치는 영향
6. 실제 활용 예시
7. 오늘 실행할 수 있는 행동
8. 핵심 요약

### 산출물

```text
핵심 독자:
독자의 문제:
한 문장 핵심 메시지:
제목 후보 3개:
콘텐츠 구성:
실무 활용 예시:
독자의 다음 행동:
```

## 8. Step 6 — 원고 작성

### 담당

Writer Agent

### 작성 기준

- 결론을 먼저 제시한다.
- 짧고 명확한 문장을 사용한다.
- 전문용어는 풀어서 설명한다.
- 확인된 사실과 해석을 구분한다.
- 과장, 공포 조장, 근거 없는 단정을 피한다.
- 독자가 자신의 업무에 적용할 예시를 포함한다.
- 원문의 표현을 길게 복제하지 않는다.

### 기본 결과물

- 유튜브 본편 대본
- Shorts 대본
- 블로그 초안
- 뉴스레터 초안
- SNS 게시물 초안

모든 형식을 항상 만들 필요는 없다. 요청된 플랫폼에 필요한 결과물만 제작한다.

## 9. Step 7 — 디자인 및 영상 기획

### 담당

Design Agent, Video Agent

### Design Agent 작업

- 인포그래픽 정보 구조 설계
- 카드뉴스 페이지 구성
- 네 컷 만화 스토리보드
- 썸네일 문구와 시각적 우선순위 제안

### Video Agent 작업

- 장면별 구성
- 내레이션과 화면 자료 연결
- 자막용 짧은 문장 작성
- 영상 도입부와 마무리 구성

### 기준

- 시각 요소는 내용을 쉽게 이해하도록 도와야 한다.
- 이미지 안의 글자를 최소화한다.
- 사실과 다른 장면을 실제 사건처럼 표현하지 않는다.
- 저작권과 초상권을 확인한다.

## 10. Step 8 — 플랫폼별 재구성

### 담당

Writer Agent, Marketing Agent

하나의 원고를 그대로 복사하지 않고 플랫폼에 맞게 바꾼다.

| 플랫폼 | 기본 방향 |
|---|---|
| YouTube | 맥락, 사례, 설명 중심 |
| Shorts | 핵심 한 가지와 빠른 전달 |
| Blog | 검색과 이해를 돕는 구조화된 글 |
| Newsletter | 핵심 뉴스와 편집자의 해석 |
| LinkedIn | 직장과 산업에 미치는 영향 |
| Instagram | 한눈에 이해되는 시각적 요약 |

## 11. Step 9 — 품질 검수

### 담당

QA Agent

### 검수 항목

- [ ] 제목과 내용이 일치한다.
- [ ] 핵심 사실, 숫자, 날짜가 정확하다.
- [ ] 원문 출처가 기록되어 있다.
- [ ] 사실과 의견이 구분되어 있다.
- [ ] 초보자도 이해할 수 있다.
- [ ] 직장인을 위한 실무적 의미가 있다.
- [ ] Sunny의 말투와 원칙을 따른다.
- [ ] 맞춤법과 문장이 자연스럽다.
- [ ] 저작권, 개인정보, 회사 기밀 문제가 없다.
- [ ] 과장이나 오해를 부르는 표현이 없다.
- [ ] 사람의 확인이 필요한 부분이 표시되어 있다.

문제가 발견되면 담당 에이전트에게 수정 요청을 보낸다. QA Agent가 검증되지 않은 내용을 직접 만들어 채우지 않는다.

## 12. Step 10 — 최종 승인

### 담당

Sunny CEO Agent와 사람 운영자

Sunny는 다음 항목을 종합 검토한다.

- 회사의 비전과 대상 독자에 맞는가?
- 지금 발행할 가치가 있는가?
- 내용이 정확하고 유용한가?
- 브랜드 신뢰를 해칠 위험이 없는가?
- 독자의 다음 행동이 분명한가?

외부 발행은 사람 운영자의 최종 승인 후 진행한다.

## 13. Step 11 — 발행 및 기록

### 담당

Marketing Agent와 사람 운영자

### 기록 항목

```text
콘텐츠 제목:
주제:
발행일:
플랫폼:
발행 URL:
핵심 대상:
성과 지표:
독자 반응:
개선 사항:
```

발행 후 얻은 개선 사항은 관련 SOP, 템플릿, 지식 문서에 반영한다.

## 14. Stop Conditions

다음 상황에서는 제작 또는 발행을 중단하고 사람에게 알린다.

- 핵심 사실을 검증할 수 없는 경우
- 출처 간 내용이 중대하게 충돌하는 경우
- 개인정보나 회사 기밀이 포함된 경우
- 저작권 또는 법적 위험이 의심되는 경우
- 의료, 법률, 금융 등 고위험 조언이 포함되는 경우
- 외부 게시나 연락에 대한 승인이 없는 경우
- Sunny의 원칙과 사용자의 요청이 충돌하는 경우

## 15. File Naming Rule

콘텐츠 관련 파일은 다음 형식을 권장한다.

```text
YYYY-MM-DD_topic_platform_version.md
```

예시:

```text
2026-08-02_gpt-update_youtube_v0.1.md
```
